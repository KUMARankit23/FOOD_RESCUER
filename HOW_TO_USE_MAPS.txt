================================================================================
                    🗺️  HOW TO TRACK VIA MAPS
================================================================================

THREE WAYS TO ACCESS MAP TRACKING:

================================================================================
METHOD 1: WEB DASHBOARD (EASIEST - RECOMMENDED)
================================================================================

STEP 1: Open Dashboard
  → Go to: http://localhost:8501

STEP 2: Navigate to Map
  → Look for sidebar on the left
  → Click: "Map Tracking"

STEP 3: See Your Map
  → Interactive map appears
  → Shows all donor and recipient locations
  → Shows active delivery routes

STEP 4: Understand the Map
  🔴 Red Pins   = Food Sources (Donors)
  🟢 Green Pins = Food Recipients
  🔵 Blue Lines = Delivery Routes
  📍 Circles    = Active Dispatches

STEP 5: View Statistics
  Below the map, you'll see:
  - Total Dispatches
  - Distance Covered (km)
  - Active Routes
  - Delivery Status

STEP 6: Download Map
  → Click: "📥 Download Map as HTML"
  → Save as: operation_map.html
  → Share with stakeholders

================================================================================
METHOD 2: REST API (FOR DEVELOPERS)
================================================================================

GET ALL TRACKING DATA:
  curl http://localhost:8000/api/v1/map/tracking

GET STATISTICS:
  curl http://localhost:8000/api/v1/map/statistics

GET DONOR LOCATIONS:
  curl http://localhost:8000/api/v1/map/donors

GET RECIPIENT LOCATIONS:
  curl http://localhost:8000/api/v1/map/recipients

GET DISPATCH HISTORY:
  curl http://localhost:8000/api/v1/map/history

GENERATE HTML MAP:
  curl -X POST http://localhost:8000/api/v1/map/generate-html

================================================================================
METHOD 3: PYTHON INTEGRATION
================================================================================

import requests

# Get all tracking data
response = requests.get('http://localhost:8000/api/v1/map/tracking')
data = response.json()

# Print dispatch details
for dispatch in data['dispatches']:
    print(f"From: {dispatch['donor_location']}")
    print(f"To: {dispatch['recipient_name']}")
    print(f"Status: {dispatch['status']}")
    print()

================================================================================
STATISTICS EXPLAINED
================================================================================

Total Dispatches
  → How many food rescue operations in total
  → Increases each time food is dispatched
  → Example: 5 operations = 300 portions redistributed

Distance Covered
  → Total kilometers traveled
  → Calculated using GPS coordinates
  → Helps estimate fuel costs
  → Example: 12.5 km for current operations

Active Routes
  → How many deliveries are happening now
  → Updates in real-time
  → Example: 2 trucks on the road

Delivered
  → Completed operations
  → Food successfully received by recipients
  → Example: 3 deliveries finished

Status Distribution
  → Breakdown by status
  → Pending: Waiting to pick up
  → In Transit: On the way
  → Delivered: Already delivered

================================================================================
TROUBLESHOOTING
================================================================================

Problem: No map showing on dashboard
Solution:
  1. Restart Streamlit (Stop and start)
  2. Try refreshing the page
  3. Check browser console for errors

Problem: No data appearing on map
Solution:
  1. Submit a report first
  2. Refresh the dashboard
  3. The route should appear

Problem: API not responding
Solution:
  1. Check if API is running: curl http://localhost:8000/health
  2. Restart API if needed
  3. Check for port conflicts

Problem: Coordinates wrong
Solution:
  1. Verify coordinates in tools.py
  2. Format should be [latitude, longitude]
  3. Example: (40.8075, -73.9626) is correct
